Setup Guide ▾
  1. Create new Google Sheets file
  2. Add 2 sheets: Weather and Athlete_Obs
  3. Weather headers: timestamp | wind_zone | wind_deg | wind_dir | wave | air_temp | cur_str | cur_deg | cur_dir | water_temp | notes | synced_at
  4. Athlete_Obs headers: timestamp | athlete | code | categories | text | synced_at
  5. Menu → Extensions → Apps Script
  6. Paste code below:
    function doPost(e){ const d = JSON.parse(e.postData.contents); const ss = SpreadsheetApp.getActiveSpreadsheet(); if(d.type==='weather'){ const ws=ss.getSheetByName('Weather'); const w=d.data; ws.appendRow([w.ts,w.wind_zone||'',w.wind_deg||'', w.wind_dir||'',w.wave||'',w.air_temp||'', w.cur_str||'',w.cur_deg||'',w.cur_dir||'', w.water_temp||'',w.notes||'', new Date().toISOString()]); } else { const as=ss.getSheetByName('Athlete_Obs'); d.data.forEach(o=>{ as.appendRow([o.ts,o.athlete||'',o.code||'', o.categories||'',o.text, new Date().toISOString()]); }); } return ContentService.createTextOutput('ok'); }
  7. Deploy → New deployment → Web app → Access: All users → Deploy
  8. Paste deployment URL above
