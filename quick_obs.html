📋 Google Sheets 연동 설정 방법 보기 ▾
  1. Google Sheets 새 파일 생성
  2. 헤더 행 추가: timestamp | athlete | code | category | text | synced_at
  3. 메뉴 → 확장 프로그램 → Apps Script
  4. 아래 코드 붙여넣기:
    function doPost(e){ const data = JSON.parse(e.postData.contents); const sheet = SpreadsheetApp.getActiveSheet(); data.observations.forEach(o=>{ sheet.appendRow([o.ts,o.athlete||'',o.athleteCode||'', o.category,o.text,new Date().toISOString()]); }); return ContentService.createTextOutput('ok'); }
  5. 배포 → 새 배포 → 웹 앱 → 액세스: 모든 사용자 → 배포
  6. 배포 URL을 위 입력창에 붙여넣기
